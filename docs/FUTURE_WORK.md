# Future Work

The current project establishes a complete prototype for traffic intelligence, graph representation, simulation, and decentralized traffic control. The following extensions can take the system toward a more advanced research platform.

## 1. Graph Neural Networks

Extend the current GNN-ready traffic graph into a trained spatio-temporal GNN for improved traffic-state forecasting.

## 2. Trained Multi-Agent RL

Replace the current decentralized heuristic controller with trained MARL algorithms such as MAPPO or graph-based multi-agent reinforcement learning.

## 3. Larger Traffic Networks

Scale the SUMO environment from the current 2×2 grid to larger and more realistic urban road networks.

## 4. Improved Traffic Modeling

Integrate additional features such as road topology, traffic incidents, weather, and real-time traffic information.

## 5. Realistic Digital Twin

Develop a more closely calibrated simulation environment using real-world road geometry, traffic demand, and signal timing data.

## 6. Advanced Evaluation

Run multiple random seeds, larger simulation scenarios, and statistical significance tests to improve the reliability of control comparisons.

## 7. Real-Time Deployment

Explore a real-time traffic intelligence and control pipeline capable of continuously receiving traffic observations and producing adaptive control decisions.

---

### Long-Term Research Direction

The long-term goal is to combine:

**Spatio-Temporal GNN + Multi-Agent Reinforcement Learning + Realistic Traffic Simulation**

into a scalable intelligent transportation system for adaptive urban traffic management.
